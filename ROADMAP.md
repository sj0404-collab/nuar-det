# Нуар-Дет — план новых фич

Детективная метроидвания «Нуар-Дет» (WebGL + Three.js, карточные бои,
ветвящиеся диалоги, PWA-подобный WebGL-трендс в портретном режиме).

Этот документ фиксирует **три запланированные фичи** и порядок их реализации.
Обновляется по мере продвижения: отмеченные ✅ пункты — реализованы, ✔ — частично.

## 1. Смена дня и ночи с циферблатом и стрелками часов

- Полноценный цикл «день ↔ ночь» в реальном времени (управляемая скорость, настраиваемая).
- **Часы на HUD** в стиле нуар: аналоговый циферблат с движущимися стрелками
  (часовой, минутной, секундной), тик-метки, цифровое время под циферблатом,
  иконка дня/ночи (солнце/луна).
- Плавный переход освещения и неба:
  - тёплый закатный/рассветный градиент «SkyDome» (переключение цветов uTop/uMid/uHor/uGlowY);
  - изменение **солнечного света** (дир./полусферового) — интенсивность и цвет;
  - **фонари** загораются в сумерках, гаснут днём (глобусы/пламя, свечение);
  - туман и окна: холодные ночные тона → тёплые дневные.
- F2-подобный демо-режим: быстрая прокрутка цикла, чтобы увидеть переход.

**Файлы:** `src/render/SkyDome.js`, `src/ui/HUD.js` + разметка HUD в `index.html`,
`src/Game.js` (обновление света в цикле), стили в `src/ui/style.css`.

## 2. Боевая система в стиле «Ю-Ги-О! Arc-V» — голографическая арена и анимации

- Вписанная в мир **голографическая проекционная арена** (без отдельного экрана
  плотно в канвас): подсветка пола боя, скан-линии, сетка «голопроектора» вокруг
  врага, как в аниме про дуэли на нулевых аренах.
- Вражеский монстр проецируется как **голограмма**: полупрозрачный, с
  мерцанием/фликером, сияющим контуром и «лучом проекции» сверху.
- Анимации боёвки:
  - призыв карты: проекционная вставка эффекта «призыв» (вспышки, кольцо, залп частиц);
  - удар по врагу: всплеск частиц в цвет карты, кольцевой шок-волной, дёшевейно;
  - замах/атака врага: «интент» — телеграфирующийся удар, уклон в сторону;
  - блок/защита — частицы щита голубого оттенка;
  - победа/поражение — триумфальный/туманный финальный эффект.
- Совместимо с текущей механикой `src/cards/Combat.js` (карты, энергия, блок,
  стадии врага), чисто визуальный слой поверх данных боя.

**Файлы:** новые модули под голопроекцию (частицы/эффекты), `src/cards/Combat.js`
(хуки событий), `src/core/Effects.js`, рендер-материалы.

## 3. Автоозвучка диалогов (TTS) с уникальным голосом для каждого персонажа

- Каждая **реплика и каждая строка диалога** озвучиваются автоматически при показе.
- **У каждого персонажа — свой голос**: свой тембр, высота/тон, темп, интонация.
  Выбирается из доступных источников (приоритет):
  1. **Edge TTS** (сеть) — естественные голоса (NN), лучший тембр;
  2. **Web Speech API / device voices** (speechSynthesis) — локальные голоса устройства;
  3. WebAudio-«декламация» как запасной вариант без сети.
- Настройки: громкость озвучки, включение/выключение, скорость речи.
- Тайминг: озвучивание стартует вместе с рендером реплики, обрывается при
  переходе/закрытии диалога; реплики идут по очереди у разных NPC — тишина
  перезапускается для нового спикера.

**Файлы:** новый модуль озвучки (обёртка над speechSynthesis/Edge TTS + фолбэк),
`src/ui/DialogueUI.js` (хук при каждом рендере реплики), данные персонажей в
`src/story/data.js` (голос/тембр/темп/интонация).
