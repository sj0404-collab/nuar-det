# Нуар-Дет — план доработок (ROADMAP)

Карточный детектив «Нуар-Дет» (WebGL + Three.js, метроидвания в портрете,
диалоги с развилками, карточные бои в духе Ю-Ги-О! Arc-V голо-арен).

Ниже — план трёх крупных фич. Порядок: сначала смена дня/ночи с часами
(видна сразу, не зависит от боёвки), затем голографическая Голо-Арена
боёвки в стиле Arc-V, затем автоозвучка всех диалогов TTS с уникальными
голосами персонажей.

---

## 1. День/ночь с часами и движущимися стрелками

**Цель:** полноценный цикл времени с видимыми «часиками» на HUD — циферблат,
часовая/минутная/секундная стрелки, плавно идущие по кругу; мир меняет
освещение и цвета неба в течение дня.

### Механика
- **Глобальное игровое время** `gameTime` привязано к **реальному дню устройства**
  (полноценные 24 часа = 24 часа по часам ОС): полночь → предрассветье → день →
  закат → ночь совпадают с настоящим временем. Лёгкий цикл с плавными
  переходами; в паузе можно «остановить время» для ночных/дневных сцен.
- **Часы на HUD** (в `HUD.js` + разметка в `index.html`):
  - круглый циферблат со штрихами-часами;
  - **часовая, минутная, секундная стрелки** — вращаются из расчёта текущего времени;
  - цифровое представление времени (ЧЧ:ММ);
  - иконка солнца/луны.

### Визуал дня/ночи
- **Небо** (`SkyDome.js`): интерполяция палитр между днём (мягкий пастельный
  туман, льдистый верх) и ночью (тёмный нуар, тёплый горизонт, звёзды ярче).
  Передача `uTop/uMid/uHor/uGlowY` в шейдер через суточный параметр.
- **Свет в мире:** днём — холодный рассеянный свет + тепло ламп почти
  незаметно; ночью — окна/фонари светятся ярче, рождаются тени.
- **Туман и дымка** — днём светлее и суше, ночью гуще и холоднее.
- Переходы — плавные (несколько секунд), без рывков; сумерки самые
  атмосферные (пурпурно-пряный градиент над линией горизонта).

### Управление
- Настройка в паузе: синхронизация с устройством / остановка времени.

**Файлы:** `src/world/SkyWorld.js` — суточные палитры;
`src/render/SkyDome.js` — интерполяция неба; `src/ui/HUD.js` + `index.html` —
часы на HUD; `src/render/GlowSprites.js` — подсветка окон/фонарей;
`src/core/timecycle.js` — утилиты (утро/день/вечер/ночь, интерполяция
градиентов). Обновление `sky.update(t)`, `world.updateLights(timeOfDay)`.

## 2. Голо-Арена боя в стиле Ю-Ги-О! Arc-V

**Цель:** превратить карточные бои в «дуэль на голографической арене» —
голубыми проекциями, проекционными столами, анимированными гроб-мобами
(чудовища), вспышками призыва существ и ударов, как в аниме «Ю-Ги-О! Arc-V».

### Механика
- **Голографические проекции вместо плоских карт** в бою (`CombatUI.js`):
  - враг-«соперник» проецируется в центре арены как грандиозное голо-существо
    (собирается из низкополигональных фигур `AnimeFigure` + подсветка
    голубыми/циановыми контурами, «скин-линиями», полупрозрачность, мерцание);
  - когда вы разыгрываете карту — на арене вспыхивает **призыв голо-чудовища**:
    проекционный круг, кольцо призыва, взлетающие искры + сама «карта» висит
    в воздухе и оборачивается, как в Arc-V;
  - атака — голо-чудовище «выстреливает» проецируемым лучом/снарядом во врага,
    попадание — взрыв частиц, тряска камеры, вспышка;
  - вражеские интенты — телеграфируются «голо-индикаторами» над головой врага.
- **Анимации** частично через существующие `Particles.js` / `GlowSprites.js`
  (у проекта уже есть engine частиц и свечения — добавить Arc-V-стайл глитч,
  сканирующие линии, «проекторный шум»).
- **Стол-арена:** под боем — полупрозрачный голубой стол-проекция с сеткой,
  кольцом арены, скан-линиями (canvas-спрайт + шейдерный свечение).

### UX
- Понадобится чуть больше места на экране: арена компактная, вписывается в
  существующий портретный экран боя, HUD-статы остаются.
- Скорость анимаций умеренная, чтобы на мобильных не тормозить: до 60 FPS
  за счёт merged-geometry и простых примитивов.
- Звуки: призыв «крик голо»+ струна, удар — бас, хит — короткий импульс.

**Файлы:** `src/ui/CombatUI.js` — рендер арены и проецируемых фигур;
`src/cards/Combat.js` — события боя (призыв/атака/блок/победа) → хуки на
анимации; `src/render/HoloArena.js` — проекционный стол-арена + эффекты;
`src/render/GlowSprites.js`, `src/render/Particles.js` — частицы/лучи;
`src/audio/AudioSys.js` — новые SFX; `index.html` — контейнер голо-арены
(`#holo-stage`), CSS.

## 3. Автоозвучка всех диалогов (TTS) с уникальными голосами

**Цель:** каждая реплика и каждый диалог автоматически озвучиваются —
погружение. У каждого персонажа (и каждой реплики) — **свой голос**:
тембр, темп, интонация, высота, «портрет голоса».

### Подход
- **Приоритет источников голоса:**
  1. **Edge TTS / облачные голоса** (если доступны) — самые выразительные;
  2. **Web Speech API (`speechSynthesis`)** — системные голоса устройства
     (iOS/Android/ПК), выбираем наиболее «нуарные»;
  3. **Локальный осцилляторный «декламатор»** (WebAudio) — запасной синтез
     «шёпотного» голоса с модуляцией высоты, чтобы даже без голосов игра
     озвучивалась (монотонный нуарный баритон с вариациями).
- **Профили голоса через «портрет голоса»** для каждого персонажа:
  - базовый тон/высота (pitch base),
  - темп (rate),
  - тембр (waveform: sine/square/sawtooth/triangle при синтезе; голосовое
    устройство выбирается по маске),
  - интонация/модуляция (jitter, glissando на концах фраз),
  - «характер» (спокойный детектив-хрип, надтреснутая старуха, синтезированный
    голос призрака — больше дрожания/эха).
- **Интонация** добавляется знаками препинания: восклицание — выше и громче,
  вопрос — подъём в конце, троеточие — затухание с паузой.
- Реализация: новый модуль `src/audio/VoiceEngine.js` — единый фасад:
  - `speak(line, profile)` — выбрать источник, произнести;
  - `stop()` — оборвать при закрытии/смене реплики;
  - `voices` — кэш доступных голосов устройства;
  - фолбэк-синтезатор (WebAudio) с профилем (база, тип волны, темп,
    модуляция), чтобы работало всегда;
  - очередь: реплики из `DialogueUI` ставятся в очередь и читаются с паузами;
  - озвучка диалога триггерится при `render()` `DialogueUI`/`Dialogue.js`.
- Настройки в паузе: вкл/выкл озвучки, источник (Auto/Edge/WebSpeech/WebAudio),
  громкость, скорость, выбор «все голоса вкл/титры+озвучка».

### Данные голосов персонажей
- `src/story/profiles.js` — карта `speaker → профиль голоса`
  (тембр, база, темп, интонация, маска голоса устройства).
- Уникальный «голосовой портрет» у каждого: Рок, Туманная Тень, Жестянщик,
  Мадамме, Айви, хранитель башни, эховисп — отличаются.

### Реализовано (v1.5.0)
- `src/audio/VoiceEngine.js`: фасад с приоритетом источников — Web Speech API
  (если есть голоса устройства) → WebAudio-«декламатор» (силлебные капли
  с глиссандо, шумовые согласные, эхо-хвост для призраков);
- интонация по знакам препинания (? — подъём, ! — громче/выше,
  … — затухание с паузой), настройка вкл/выкл в «Настройках» (`btn-voice-toggle`,
  сохраняется в localStorage `nuar_voice`);
- озвучка триггерится из `render()` `DialogueUI` (хук `onSpeak`) и для финала
  `FINAL`; `voice.stop()` на закрытии диалога и концовке.

**Файлы:** `src/audio/VoiceEngine.js` (новый), `src/story/profiles.js` (новый),
интеграция `src/ui/DialogueUI.js` (хук `onSpeak`), `src/Game.js`
(`onDialogueSpeak`, `toggleVoice`), `index.html`, `Screens.js` — настройки.

**Файлы:** `src/audio/VoiceEngine.js` (новый), `src/story/profiles.js` (новый),

## 4. Сохранения (v1.5.9 — реализовано)

- Единый слот `nuar_save_v1` в localStorage: чекпоинт, флаги, сид концовки,
  колода, инвентарь (ключи-улики), способности, открытые сундуки, взятые
  предметы, поверженные мороки, `bossDefeated`.
- **Автосейв** при входе в новую зону (чекпоинт), спуске/подъёме цистерны и
  после победы над боссом; ручное «Сохранить игру» в паузе.
- **Титул:** «Продолжить дело» (виден при наличии сохранения) + строка
  «Сохранение: <дата>»; «Начать расследование» / «Сыграть заново» с
  подтверждением перезаписи через `confirm`.
- Экран загрузки крутит подсказки по городу.
- Восстановление: позиция→чекпоинт, повторная синхронизация ворот
  (`checkGatesAuto`), скрытие открытых сундуков/взятых ключей/мёртвых мороков.

**Файлы:** `src/Game.js` (`saveGame/loadGame/continueGame/newGame/autosave`),
`src/ui/Screens.js` (кнопки «Продолжить»/«Сохранить», статус), `index.html`,
`src/main.js` (подсказки загрузки), `src/ui/style.css`.

- **Поражение** — уже есть (`hp=40` + возврат на чекпоинт): проверить и

### 5.2 Камера и миникарта (v1.6.0)
- Режимы вида: орбита (текущий), **от первого лица**, **вид сверху**;
  переключение кнопкой/клавишей V, сохранение выбора.
- **Миникарта-компас** в углу HUD (canvas): зоны/дорожки, маркер игрока,
  стрелка курса по yaw камеры (N/S/E/W).

### 5.3 Настройки (v1.6.1)
- **Выбор движка озвучки** — источник голоса реплик (`VoiceEngine.mode`,
  сейчас прибит к `auto`; хранить в `nuar_tts_mode`):
  - `auto` — авторазбор по мере доступности;
  - `edge` — **Edge TTS Read Aloud** (прямой WS в Edge или через
    self-hosted relay `nuar_tts_relay` — OpenAI-совместимый прокси);
  - `google` — **Google TTS** (неофициальный endpoint gTTs / relay);
  - `web` — **системный Web Speech API** (голоса устройства);
  - `synth` — локальный **WebAudio-«декламатор»** (всегда работает офлайн).
- **Выбор голоса** внутри движка: профиль/тембр/темп/высота персонажа
  (`profiles.js`), для системы — конкретный системный голос; кнопка
  «Попробовать» (превью-реплика).
- Включение/выключение озвучки остаётся как сейчас (`btn-voice-toggle`).
- **Инверсия камеры по горизонтали** отдельно от вертикальной
  (сейчас тумблер лишь вертикальный).

### 5.4 Транспорт (v1.6.2)

### 5.5 Обучение при первом столкновении (v1.6.3)

  (карты/энергия/ход), первая способность (прыжок/рывок/стенка/лупа),
  первый ключ-улика, первая развилка диалога. Запоминаются в localStorage,
  доступны из «Как играть».
